MATCHA MOON — موقع متجر تجريبي
================================

التشغيل:
1) فكّي ضغط الملف ZIP (إن كنتِ تستخدمين النسخة المضغوطة).
2) افتحي index.html في متصفح حديث مثل Chrome أو Edge.
3) يجب إبقاء مجلد assets بجوار index.html حتى تظهر الصور.

المحتويات:
- index.html: بنية الموقع والأقسام العربية.
- style.css: الهوية البصرية والتنسيق المتجاوب للجوال والكمبيوتر.
- app.js: تصفية المنتجات والبحث وسلة المشتريات ونموذج الطلب التجريبي ونموذج التواصل.
- assets/: الصور والشعار المرفقة بعد تهيئتها للاستخدام على الويب.

ملاحظات مهمة:
- جميع الأسعار بالريال السعودي كما وردت في تفاصيل المشروع.
- سلة المشتريات تعمل داخل المتصفح في أثناء فتح الموقع؛ لا يوجد خادم أو قاعدة بيانات.
- نموذج التواصل والطلب للتجربة والعرض الدراسي فقط. لا تُرسل البيانات إلى أي جهة خارجية ولا يتم تنفيذ دفع أو شحن فعلي.
- الخط الخارجي قد يحتاج إلى اتصال بالإنترنت؛ توجد خطوط بديلة إذا لم يتوفر.

إعداد الطالبات: مرام - نوره - جوري
